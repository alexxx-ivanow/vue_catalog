# Модуль `abcwww.markers` — описание на русском

## Назначение

`abcwww.markers` добавляет в 1С-Битрикс функционал интерактивных меток на изображении:

- схема (изображение-подложка) хранится в разделе инфоблока;
- метки хранятся как элементы внутри выбранного раздела;
- на сайте схема выводится через компонент `abcwww:markers` или через HTML-сниппет с `data-атрибутами`.

---

## Как устроены данные

Модуль использует служебный инфоблок (создаётся при установке модуля) и UF-поля.

### UF-поля раздела (настройки схемы)

- `UF_MARKER_IMAGE` — картинка-подложка;
- `UF_MARKER_MAIN_COLOR` — основной цвет маркеров;
- `UF_MARKER_ICON` — SVG-иконка маркера;
- `UF_MARKER_ICON_PC` — размер иконки на ПК;
- `UF_MARKER_ICON_MB` — размер иконки на мобильных;
- `UF_MARKER_ACTIVE_COLOR` — цвет активной/hover метки.

### UF-поля элемента (настройки метки)

- `UF_MARKER_X` — координата X в процентах (0..100);
- `UF_MARKER_Y` — координата Y в процентах (0..100);
- `UF_MARKER_MODAL_ONLY` — открывать только модальное окно;
- `UF_MARKER_COLOR` — цвет метки;
- `UF_MARKER_HOVER_COLOR` — цвет метки при hover/active;
- `UF_MARKER_OPENED` — метка раскрыта по умолчанию;
- `UF_MARKER_HIDE_MORE` — скрыть кнопку «Подробнее»;
- `UF_MARKER_BTN_TEXT` — текст кнопки товара;
- `UF_MARKER_BTN_COLOR` — цвет кнопки товара;
- `UF_MARKER_URL` — URL товара.

Дополнительно используются стандартные поля элемента:

- `PREVIEW_PICTURE` и `PREVIEW_TEXT` — контент анонса (tooltip);
- `DETAIL_PICTURE` и `DETAIL_TEXT` — контент модального окна.

---

## Настройки модуля

Файл настроек: `local/modules/abcwww.markers/options.php`.

Доступные параметры:

- `IBLOCK_ID` — ID служебного инфоблока с картами/метками;
- `ENABLE_SNIPPET_AUTO_INIT` — включение автоинициализации сниппета:
  - `<div data-wnfgr="markers" data-id="{SECTION_ID}" data-iblock-id="{IBLOCK_ID}"></div>`;
- кнопка `Создать/обновить UF-поля` — создаёт необходимые UF-поля для выбранного `IBLOCK_ID`.

## Принцип работы

## 1) Установка

При установке модуль:

- регистрируется в системе;
- копирует компоненты, JS/CSS, admin/tools файлы;
- регистрирует обработчики событий;
- создаёт служебный тип инфоблока и служебный инфоблок (если отсутствуют);
- автоматически создаёт UF-поля для служебного инфоблока.

## 2) Админ-часть

- На странице редактирования раздела инфоблока появляется кнопка перехода в визуальный редактор.
- Визуальный редактор:
  - открывает изображение схемы;
  - двойной клик по изображению создаёт метку с вычислением `%` координат;
  - позволяет редактировать/удалять метки по AJAX.

AJAX endpoint: `/bitrix/tools/abcwww.markers/ajax.php`.

## 3) Публичная часть

### Вариант A: компонент

```php
$APPLICATION->IncludeComponent(
    "abcwww:markers",
    ".default",
    [
        "IBLOCK_ID" => "...",
        "SECTION_ID" => "...",
        "SORT_BY1" => "NAME",
        "SORT_ORDER1" => "ASC",
        "SORT_BY2" => "ID",
        "SORT_ORDER2" => "DESC",
        "CACHE_TYPE" => "A",
        "CACHE_TIME" => "3600000",
    ]
);
```

### Вариант B: HTML-сниппет

```html
<div data-wnfgr="markers" data-id="123" data-iblock-id="2"></div>
```

Если включён `ENABLE_SNIPPET_AUTO_INIT`, модуль сам найдёт такие блоки и отрисует метки.

## 4) Отрисовка меток

- позиционирование: `left: X%; top: Y%`;
- размеры иконок зависят от устройства (`UF_MARKER_ICON_PC` / `UF_MARKER_ICON_MB`);
- цвета берутся из настроек схемы с возможностью переопределения на уровне метки;
- по клику открывается tooltip или сразу modal (в зависимости от `UF_MARKER_MODAL_ONLY`).

## 5) Логика кнопок в tooltip

- если есть URL товара и выполнено условие
  - `UF_MARKER_HIDE_MORE = Y` **или** нет детального текста,
  - показывается кнопка товара;
- иначе показывается кнопка «Подробнее» для открытия модального окна;
- если кнопки не нужны по условиям — не выводятся.

---

## Кеширование и сброс кеша

- кеш компонента: путь `/abcwww_markers/`;
- при изменении элементов/разделов служебного инфоблока кеш сбрасывается обработчиками модуля.

---

## Деинсталляция

При удалении модуля:

- удаляются обработчики событий и файлы модуля;
- удаляются UF-поля `UF_MARKER_*`;
- удаляется служебный инфоблок (если он создан модулем);
- удаляется тип инфоблока (если он пустой);
- удаляются настройки модуля.
