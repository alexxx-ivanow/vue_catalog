# Инструкция для контент-менеджера (`abcwww.markers`)

## 1) Подготовка

1. Убедитесь, что модуль `abcwww.markers` установлен.
2. В настройках модуля проверьте `IBLOCK_ID` (служебный инфоблок меток).
3. Если нужно, нажмите `Создать/обновить UF-поля`.

## 2) Создание интерактивной схемы

1. Откройте служебный инфоблок.
2. Создайте раздел (это и есть «схема»).
3. В разделе заполните:
   - картинку-подложку;
   - основной цвет;
   - размеры иконок (ПК/мобильный);
   - при необходимости — кастомную SVG-иконку.

## 3) Добавление меток

1. Откройте созданный раздел на редактирование.
2. Нажмите `Открыть визуальный редактор меток`.
3. В редакторе:
   - двойной клик по картинке создаёт метку;
   - в таблице ниже метку можно редактировать или удалить.
4. Для каждой метки при необходимости откройте элемент в новой вкладке и заполните:
   - `PREVIEW_TEXT` / `PREVIEW_PICTURE` (анонс в тултипе),
   - `DETAIL_TEXT` / `DETAIL_PICTURE` (контент модального окна),
   - URL товара и настройки кнопки.

## 4) Вывод на сайте

### Вариант A: через компонент

```php
$APPLICATION->IncludeComponent(
    "abcwww:markers",
    ".default",
    [
        "IBLOCK_ID" => "2",
        "SECTION_ID" => "123",
        "CACHE_TYPE" => "A",
        "CACHE_TIME" => "3600000"
    ]
);
```

### Вариант B: через сниппет

```html
<div data-abcwww-snippet="markers" data-id="123" data-iblock-id="2"></div>
```

Если в настройках включена автоинициализация, модуль сам отрисует схему.

## 5) Проверка результата

- Метки стоят в нужных местах;
- tooltip открывается по клику;
- кнопка «Подробнее»/кнопка товара отображается по правилам;
- модальное окно открывается и закрывается (крестик / клик вне / Esc);
- на мобильном размер маркеров меньше, чем на ПК.

## 6) Частые проблемы

- **Схема не видна:** проверьте `UF_MARKER_IMAGE` у раздела.
- **Метки не выводятся:** убедитесь, что элементы активны и лежат в нужном разделе.
- **Сниппет не работает:** проверьте `data-id`, `data-iblock-id` и включенную автоинициализацию.
- **Изменения не видны сразу:** очистите кеш Битрикс.
